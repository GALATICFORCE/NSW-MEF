# NSW hourly marginal emissions (MEF): labels, baselines and AEI

Code for the MEF part of an ENGG2112 group project: *Forecasting Hourly Marginal Emissions Factors for New South Wales Using Machine Learning*. It builds hourly MEF labels for the NSW1 region (July 2025 to June 2026), naive forecast baselines with evaluation metrics, and a 5-minute average emissions intensity (AEI) series.

## Layout
- `src/`: all scripts (run from the repository root)
- `docs/label_rules_v1.md`: the frozen labelling rules, including how battery-set intervals are treated (git tag `label-rules-v1`)
- `docs/aei_method_note.md`: plain-language AEI method note
- `outputs/`: validation reports, the night split and metric tables
- `data/`: generated data, not in the repository (see below)

## Reproduce
1. **Environment.** Python 3.11, then `pip install -r requirements.txt`. The versions are pinned because NEMED 0.3.3 needs pandas 1.5.3 and numpy < 2.
2. **Download MEF.** `python src/fetch_mef.py 2025-07 2026-06` downloads NEMED marginal-emissions output month by month into `data/raw/`. `src/aemo_archive_fix.py` patches AEMO's newer archive file names, which NEMED 0.3.3 does not recognise.
3. **Build the 5-minute table.**
   - `python src/build_5min_full.py` builds the table.
   - `python src/check_5min_full.py` runs the acceptance checks.
4. **Build the labels.**
   - `python src/labels.py` writes the 5-minute labels A, B, C and C-fwd.
   - `python src/build_hourly_mef.py --label C` writes the hourly table; repeat for A, B and Cfwd.
   - `python src/validate.py --labels A B C Cfwd` checks the tables.
5. **Split and baselines.**
   - `python src/nights.py` checks the train/validation/test split against `outputs/nights_split_v1.csv`.
   - `python src/baselines.py` evaluates the two naive baselines (`src/metrics.py` holds the metrics).
6. **AEI.** `python src/build_aei_5min.py` builds the NSW1 5-minute AEI. `src/aei_trial.py` is the one-day check that led to this method.

## Data
Data files are not stored here because they are large; every file under `data/` is regenerated by the steps above. The NEMED and AEMO downloads (roughly 8 GB of cache) come from AEMO's public NEMWeb archive.
